About

Shehan Dilhara is a third-year BSc (Hons) Information Technology student at the Sri Lanka Institute of Information Technology (SLIIT). His main interests are Linux system administration, IT infrastructure, DevOps, cloud computing, and AI and machine learning.

Most of his Linux experience is on Ubuntu, Fedora, and Rocky Linux. He works from the command line and has covered user and permission management, process administration, systemd services, package management, SSH, and log analysis. He is also learning server administration, system security, and networking fundamentals, and has studied how to deploy applications on Apache HTTP Server and Apache Tomcat.

On the DevOps side, he has looked at automation, version control, infrastructure as code, and cloud computing. He also uses Python for machine learning: preprocessing data, selecting features, reducing dimensions, building models, and evaluating how well they perform.

He has used these skills in academic and personal projects, including backend services, microservices, a transaction fraud detection system, and a handwritten digit recognizer. He keeps building his foundation by running experiments and starting new projects.
